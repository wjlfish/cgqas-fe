# 创高题库

创高体育理论考试的题库检索站点源码。

面向使用创高体育理论考试系统的高校学生，按关键词、科目、题型检索题目与答案。
**题库数据不在本仓库内。**

## 功能

- 关键词检索（题干 / 答案），可按科目与题型筛选、分页
- 手机号验证码登录，未注册自动创建账号，按账号计量检索次数
- 用户首次进入选择自己的体育课科目，检索范围限定在公共题库 + 所选科目
- 使用须知、错题申报、问题反馈、额度申请
- 管理后台：用户、访问与检索记录、限流、反馈、提额、去重审阅

## 技术栈

PHP 8 + MySQL + 原生 HTML/CSS/JS，无构建步骤。

## 目录

```
index.php        检索主界面
about.php        关于页
feedback.php     反馈与额度
api.php          JSON 接口
go.php           站内跳转
lib/             库（配置、数据库、鉴权、限流、地域、验证码）
partials/        模板片段
assets/          CSS / JS
admin/           后台源码（部署时复制到随机目录）
ops/             运维脚本
sql/             建表语句
```

## 部署

1. 复制 `lib/config.example.php` 为 `lib/config.php`，填入数据库连接、随机 `secret` 与管理口令
2. 导入 `sql/schema.sql` 建表
3. 后台源码放到随机命名的子目录
4. 屏蔽 `lib/`、`sql/`、`partials/` 等目录，PHP 仅允许内部重写访问

`ops/` 下的辅助脚本（资源哈希、推荐词索引、部署前自检）用法见各脚本注释。
